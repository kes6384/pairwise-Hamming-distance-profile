# PAIRWISE HAMMING DISTANCE PROFILE  
  
This tool includes several methods to compute the pairwise Hamming distance profile of a given sequence. It is designed for use with FASTA files with sequences of length less than 4,294,967,295 and $k$ of at most 128. The tool can be compiled and run using the command line. The results are output to a user-specified text file.  
  
The tool can be used to compute the full Hamming distance profile of a sequence, or to compute a sketch of the profile for faster (but less accurate) results. Support for multithreading is also provided.  
  
All of the provided methods are contained within profile.cpp and parseFASTA.cpp. Required open source libraries are provided in the repo. MurmurHash3 was created by Austin Appleby. The MurmurHash repo can be found here: https://github.com/aappleby/smhasher/tree/master  

## REQUIREMENTS  
  
C++ $\geq 20$  
Windows OS $\geq 11$ or Linux Ubuntu distro $\geq 24.04$  
  
Due to the use of FracMinHash, results may differ across operating systems when generating a sketch instead of the full profile.  
  
## INSTALL AND COMPILING  
  
```
git clone https://github.com/kes6384/pairwise-Hamming-distance-profile.git  
cd pairwise-Hamming-distance-profile  
g++ -O3 -fPIC -fopenmp -std=c++20 -pipe -D_FILE_OFFSET_BITS=64 -o profile profile.cpp
```
  
## RUNNING  

```
./profile -i [INPUT FILE] -o [OUTPUT FILE].txt -l [SEQUENCE LENGTH] -k [k] -s [ROW SAMPLE RATE] [COLUMN SAMPLE RATE] -t [NUMBER OF THREADS]  
```
  
The arguments can be specified using the options outlined below. Order does not matter.  
  
Required arguments:  
  
`-i <input-file>` &emsp;&emsp;&emsp;&emsp;&emsp; FASTA file containing sequence to analyze  
`-o <output-file>` &emsp;&emsp;&emsp;&emsp;&emsp; Text file for output  
`-k <kmer-size>` &emsp;&emsp;&emsp;&emsp;&emsp; K-mer size, must be between 1 and 128 (inclusive)  
  
Optional arguments:  

`-l <length>` &emsp;&emsp;&emsp;&emsp;&emsp; Sequence length (in base pairs), must be less than 4,294,967,295 (default: length of input file)  
`-s <theta_1> [<theta_2>]` &emsp;&emsp;&emsp; Generate a sketch using FracMinHash with given rate(s) (default: 1.0, no sketching)  
`-t <thread-number>` &emsp;&emsp;&emsp;&emsp; Number of threads (default: 1)  
  
### EXAMPLES  
The input used for the following examples and the results generated by them can be found in the [test folder](/test/). The input file used for these examples ([test/test.fna](/test/test.fna)) contains the first 100,023 base pairs of the [*E. coli*  0.1288 strain's genome, ASM30325v2](https://www.ncbi.nlm.nih.gov/datasets/genome/GCA_000303255.2/).  
  
Use one thread to compute the full Hamming distance profile of 32-mers for the first 10,000 characters of the sequence in test.fna, and store the results in results.txt:
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32
```
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -s 1.0 1.0
```
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -s 1.0
```
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -t 1
```
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -s 1.0 1.0 -t 1
```
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -s 1.0 -t 1
```
  
Use one thread to sample 32-mer pairs at an overall rate of 0.25 (row sampling rate 0.5, column sampling rate 0.5):
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -s 0.5 0.5
```
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -s 0.5
```
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -s 0.5 0.5 -t 1
```
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -s 0.5 -t 1
```
  
Calculate the full profile using 4 threads:
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -t 4
```
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -s 1.0 1.0 -t 4
```
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -s 1.0 -t 4
```
  
Use 4 threads to sample 32-mer pairs at an overall rate of 0.25 (row sampling rate 0.5, column sampling rate 0.5):
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -s 0.5 0.5 -t 4
```
```
./profile -i test/test.fna -o results.txt -l 10000 -k 32 -s 0.5 -t 4
```
  
## OUTPUT  
  
The output file will show the number of k-mer pairs in the input sequence that have a Hamming distance of 0, 1, ..., k. The results will be formatted in 2 columns:  
  
Hamming Distance : Number of Pairs  
  
For example output, please see the [test folder](/test/). The results files are named according to the arguments used to generate them. For example, [results_fullProfile_10000_32.txt](/test/results_fullProfile_10000_32.txt) contains the results of running a full profile (sampling rate of 1.0) with a sequence length of 10,000 and $k$ of 32. [results_sampleRate0.5_10000_32.txt](/test/results_sampleRate0.5_10000_32.txt) was generated using a row sampling rate of 0.5 and a column sampling rate of 0.5 for an overall sampling rate of 0.25. The number of threads has no effect on the output generated. All example output was generated using Windows 11.
