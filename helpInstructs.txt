Pairwise Hamming Distance Profile Tool
======================================
Compute the pairwise Hamming distance profile of a given sequence. Designed for use with FASTA files and sequences of length less than 4,294,967,295 and k of at most 128. k-mers containing characters besides A,C,T,U, and G will be ignored. Results are output to a user-specified text file. Can be used to compute the full Hamming distance profile of a sequence, or to compute a sketch of the profile for faster (but less accurate) results.  

Usage: ./profile [OPTIONS]

Required arguments:

-i <input-file>         FASTA file containing sequence to analyze
-o <output-file>        Text file for output
-k <kmer-size>          K-mer size, must be between 1 and 128 (inclusive)

Optional arguments:

-l <length>             Sequence length (in base pairs), must be less than 4,294,967,295 (default: length of input file)
-s <theta>              Generate a sketch using FracMinHash with given theta (default: 1.0, no sketching)
-t <thread-number>      Number of threads (default: 1)

Examples:
Full profile of entire file:
./profile -i /test/test.fna -o results.txt -k 32
Sketching (theta = 0.5):
./profile -i /test/test.fna -o results.txt -k 32 -s 0.5
Using a specific sequence length:
./profile -i /test/test.fna -o results.txt -k 32 -l 10000
